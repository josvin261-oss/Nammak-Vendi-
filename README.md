Nammak Vendi

“For us” — A free, offline-first student opportunity portal for Indian students.

A single HTML file that aggregates everything a student needs to get ahead — funded scholarships, internships, hackathons, free courses, university comparisons, rankings, and education news — wrapped in a brutalist, animated UI with zero backend and zero cost.

Features
40+ curated opportunities — Scholarships, internships, research seats, hackathons, courses, and communities
University guide — 9 institutions (IITs to MIT/NUS) with fees, packages, entrance routes, and a side-by-side comparison table
Education news — 12+ curated headlines across protests, rankings, AI in education, and scholarships
Rankings — NIRF Engineering 2025 and QS World 2027 (Indian institutions)
Career roadmaps — CS, Medicine, Design, and Data Science paths
Smart NLP search — Type naturally; filters auto-fill from your query
Click sounds + particle effects — Fully interactive, brutalist aesthetic
Local saves — Bookmark opportunities; stored in your browser only
Mobile-ready — Bottom tab bar, safe-area-aware, fully responsive
Usage

No install. No server. Just open the file.

Clone or download, then open Nammak_Vendi_final.html in any browser. Or just double-click the file.

Tech Stack

Structure: Vanilla HTML5
Styling: Pure CSS (custom properties, grid, flexbox)
Logic: Vanilla JavaScript (no frameworks)
Fonts: Google Fonts (Archivo Black, IBM Plex Sans/Mono, Noto Sans Malayalam)
Images: Unsplash + Picsum (lazy-loaded, fallback-safe)
Storage: localStorage (browser-only, nothing sent to a server)
